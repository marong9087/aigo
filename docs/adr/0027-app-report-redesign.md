# 0027. 분석 리포트 세 탭(요약·근거·기준)을 남색·민트 색감으로 다시 꾸민다

- 상태: 제안
- 날짜: 2026-11-13
- 변경 작업자: 최혜지 (marong9087), Claude(AI)
- 관련 PR: #번호

## 작업 내용
분석창 3가지 탭.

- 리포트 화면(`app/analyses/[id].tsx`) 머리글을 남색(`ink`)으로 바꿨다. 로고와 `REPORT` 글씨는 넣지 않는다(최혜지 요청). 제목과 날짜는 화면 가운데에 둔다(전에는 왼쪽에 붙어 있었다). 뒤로·공유 버튼은 양옆에 같은 너비로 두어 가운데 줄이 밀리지 않는다.
- 리포트 화면 바탕만 `#F4F7F9`(`reportBg`)로 바꿨다. 다른 화면의 바탕(`bg`)은 그대로다.
- 요약 탭: 지금 먼저 할 일 → 남색 "사고 분석 요약" 카드(사고 유형, 요약, 심각도, 과실 예상 범위, 기준 도표, 충돌 의심 시각) → 영상에서 확인한 장면(충돌 전후 최대 3개) → 확인되지 않은 조건 → 이후 대응 → 주의 문구.
- 근거 탭: 영상(없으면 안내 카드) → 세로 장면 타임라인(접촉 장면은 빨간 점) → 추가로 확인한 사실 → 판단에 사용한 근거(유리한 점·불리한 점) → 영상만으로 확인할 수 없는 사실.
- 기준 탭: 과실 판단 기준 카드 → 범위가 나온 과정(기본과실 → 수정요소 → 최종 범위) → 왜 하나의 숫자가 아닌가요? → 기준과 출처 → 관련 법규·참고 판례 → 중대한 위반 여부(확인된 장면 / 가능성이 제시된 항목 / 확인할 수 없는 항목).
- 새 파일 `components/report-sections.tsx`에 화면 조각을 모았다. `theme.ts`에 `mint`, `mintDeep`, `mintSoft`, `reportBg`를 더했다. 시각 칩은 0.1초까지 보인다(`formatTimePrecise`, 예: `0:11.2`).
- 민트 사용 규칙: 남색 바탕 위에는 로고 민트(`#3FCF8E`, 대비 7.05:1), 흰 바탕 위 글씨는 진한 민트(`#0B7A4D`, 5.38:1)와 연한 민트 바탕(`#E3F8EE`)을 쓴다. 로고 민트를 흰 바탕 글씨로 쓰지 않는다(1.99:1).

## 변경 사유
회색과 흰색의 조합은 깔끔하지만 사고 대응(뒤처리)라는 점을 미루어 보았을떄는 가벼운 느낌이 들고 어플의 아이콘 색과 내부 색감이 동떨어져있는 느낌으로 통일성이 없는 것 같아 색감 통일 작업을 진행 중 - 최혜지

추가로, 상단 글씨가 왼쪽으로 치우쳐 있어 화면 가운데로 옮겨 달라는 요청(최혜지)을 반영했다.

## 영향
- 서버(`apps/api`) 데이터는 바꾸지 않았고, 화면에서 새 사실을 만들지 않는다. 출처 url이 http(s)가 아니면 링크를 만들지 않고 "출처 확인 필요"로 둔다.
- 서버는 미확인 조건의 이름만 주고 조건별로 범위를 넓힌 폭은 주지 않는다. 그래서 화면은 폭을 지어내지 않고 "추가 계산 근거 확인이 필요합니다"라고 쓴다. 폭을 보이려면 서버(조준형)가 값을 내려 줘야 한다.
- 관찰/AI 추정 구분, 내 차/상대 차 구분, "방향지시등 사용 안 함"과 "보이지 않음"의 표현 차이는 서버 리포트 문장에서 정해지므로 이 변경 범위 밖이다.
- 확인: `pnpm exec tsc --noEmit`, `pnpm test`(106개 통과). 웹 빌드로 세 탭의 전·후 화면을 찍어 PR에 붙였다. 실제 안드로이드 기기에서는 아직 보지 않았다.
- 앱 전체 바탕색 변경은 별도 작업으로 남겨 둔다.
