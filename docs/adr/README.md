# ADR (결정 기록)

ADR(Architecture Decision Record)은 "무엇을, 왜, 누가 바꿨는지" 남기는 짧은 문서입니다.
나중에 다른 사람이 같은 코드를 볼 때 이유를 알 수 있게 합니다.

## 언제 쓰나요
- 관리자(조준형, jcmaker)가 아닌 사람이 올리는 **모든 PR**은 ADR 파일을 하나 추가합니다. CI가 확인합니다.
- 관리자는 구조, 기술, 운영 방식처럼 큰 결정을 할 때 씁니다.

## 쓰는 방법
1. [`0000-template.md`](0000-template.md)를 복사합니다.
2. 파일 이름은 `번호-짧은-제목.md`로 합니다. 번호는 아래 목록의 마지막 번호에 1을 더합니다. 예: `0005-home-copy-fix.md`
3. 작업 내용, 변경 사유, 변경 작업자를 빠짐없이 적습니다.
4. 아래 목록에 한 줄을 추가합니다.

0007~0021은 2026-11-09에 지난 설계 문서(`docs/superpowers/specs/`), PR, 작업 세션의 결정을 옮겨 적은 것입니다. 날짜는 결정한 날입니다. 작업자의 "조준형, Claude(AI)"는 조준형이 정하고 Claude가 세부를 설계해 조준형이 승인한 결정입니다.

이미 머지된 ADR은 고치지 않습니다. 결정이 바뀌면 새 ADR을 쓰고, 옛 ADR의 상태를 "대체됨(000N)"으로 바꿉니다.
